# EthosGuard AI

A clickable demo of an AI governance console for mid-market teams: model registry, risk and health score, bias testing, drift telemetry, policy suite, explainability matrix, audit trails, privacy guard, safety bounds, compliance map (NIST AI RMF Govern/Map/Measure/Manage as an internal checklist), model provenance (dependency and license scan) and dataset integrity / poisoning shield.

All numbers are demo data. This is a governance workflow and telemetry UI, not a legal certification or legal advice.

## Files
- `index.html` – the whole app (HTML, CSS and JS in one file). Static, works on GitHub Pages.
